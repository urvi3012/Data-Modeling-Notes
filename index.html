1. OLTP vs OLAP (AWS Standards)

Based on AWS architectural benchmarks, these are the core differences between transactional and analytical workloads.

Feature OLTP (Transactional) OLAP (Analytical)
Primary GoalOperational efficiency (recording daily tasks)Strategic decision making (historic trends)
Data ModelNormalized (3NF) - focus on data integrityDenormalized (Star/Snowflake) - focus on speed
Write FrequencyExtremely high, millisecond latencyBatch or Stream ingestion (hourly/daily)
Query ComplexitySimple lookups (Single customer record)Massive aggregations (Total sales per region)
Data SourceNative Apps, ERP, CRM systemsAggregated from multiple OLTP systems
Processing TypeACID compliant (Atomicity, Consistency)High-throughput Columnar scans
